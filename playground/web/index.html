        This page runs one file. There is no file system in the browser, so
        import reports that the program was not loaded from a file,
        and no keyboard buffer, so read_key refuses. Everything
        else is the language exactly as the command line runs it.
        Share puts the program in the address bar, in the part
        after the #, which a browser never sends to a server.
