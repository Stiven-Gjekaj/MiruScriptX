# Getting help

Need help with MiruScriptX? Here is where to look.

## Learn the language

- Start with the guided wiki, beginning at
  [wiki/01-introduction.md](wiki/01-introduction.md).
- For a single searchable page, see
  [docs/language-reference.md](docs/language-reference.md).
- To see how the interpreter is built, read
  [docs/architecture.md](docs/architecture.md).

## Ask a question or report a problem

- Search the existing
  [issues](https://github.com/stiven-gjekaj/miruscriptx/issues) first, in case
  someone has already asked.
- If you found a bug, open a bug report.
- If you want a feature, open a feature request.

Please do not use the issue tracker for security problems. See
[SECURITY.md](SECURITY.md) for how to report those privately.

## Contributing

If you would like to help improve MiruScriptX, see
[CONTRIBUTING.md](CONTRIBUTING.md).
