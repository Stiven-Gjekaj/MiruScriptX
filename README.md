# MiruScriptX

A small, general-purpose scripting language written in Rust.

MiruScriptX (files use the `.msx` extension) is a dynamically typed language
with a clean, modern syntax: first-class functions and closures, arrays, and
familiar control flow. It runs through a tree-walking interpreter with zero
external dependencies.

Status: v0.1 is in active development. A guided wiki, a full language
reference, and runnable examples are on the way.
